# Archived Processing prototype

These Processing sketches and their CSV files preserve the original desktop
prototype. They are not used by the web app or its GitHub workflows.

The prototype predates the current source validation, reference alignment,
calendar handling and combined datasets. Its curves and controls differ from
the maintained app, and it is not covered by the web regression tests.

For the current program, use [the web app](../README.md). Dataset provenance and
combination methods are documented in [data/SOURCES.md](../data/SOURCES.md).
